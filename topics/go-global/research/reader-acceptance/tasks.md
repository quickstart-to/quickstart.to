# 第一轮读者任务

这轮试读想了解：指南能否帮助你完成下一步决定，哪些地方会让你卡住。它不是收入挑战，也不需要真实付款、开户、提交税务资料或联系潜在客户。请按你目前的实际情况选择任务；可以使用合成材料，也可以随时停止。

组织者每次只发给你 1–2 项任务。先自行尝试，遇到不明白的地方就按自己的判断继续或停下，不需要猜组织者希望听到什么。请保留卡住的页面与小节，以及你原本想完成什么。耗时只用于了解摩擦，没有“越快越好”的评分。

观察记录只使用编号及脱敏结论，不默认录音、录屏或收集客户文件。站内反馈另使用 GitHub 登录，审核后会公开反馈文字和 GitHub 用户名，不能当作匿名提交；提交前请阅读 [隐私与反馈说明](https://quickstart.to/privacy)。不愿公开或登录，可以不做 T6，并在双方约定的私密渠道说明卡点。其他任务的参与不受影响。

## T1：找到下一项值得验证的问题

你有一个产品想法，但还没有确定该先做什么。使用 [快速入门](https://quickstart.to/go-global) 和 [选品与验证](https://quickstart.to/go-global/validate-idea)，写下一项你愿意先调查的具体工作。

交回一小段决定：服务谁、他现在怎样完成这件事、为什么值得先调查、你准备取得哪一份材料，以及出现什么情况会让你停止或换方向。标出对这项决定帮助最大或最难理解的小节。不需要真的去访谈或开发。

## T2：完成一份可检查的结果，再安排有限试用

你正为 Project North 准备客户更新：调研记录为 3 小时，草稿工作为 2 小时；负责人判断草稿可以审阅，下一步请客户反馈。使用 [首次使用](https://quickstart.to/go-global/first-use) 的本地样本完成一份你愿意自己核对的草稿，保存并重新打开；也试一份工时写错的样本，观察遇到问题后能否继续。无需上传自己的文件。

交回脱敏说明：你实际拿到了什么，哪里需要提示，还有哪件事没有发生。再结合自己的产品想法，写出一次有限试用的输入、结果，以及什么观察会改变你是否继续开发的决定。不要提交报告文件或客户资料，只描述结果。

## T3：解释报价，并决定下一轮投入

使用 [定价与订阅](https://quickstart.to/go-global/pricing) 和 [经营复盘](https://quickstart.to/go-global/business-review)。先解释书中 20 美元、30 天报价包含什么，购买者到期后会遇到什么；再用经营章的 9 月记录，说明你认为开发者下个月该继续、缩小还是停止，以及依据。

交回一段解释：销售与退款、银行现金、自己投入的时间分别怎样影响决定；指出一项仍未知、不能直接当作零的事项。可以采用与书中不同的选择，只要说明条件和理由。无需提供自己的收入或账单。

## T4：解释付款失败后的恢复

阅读 [收款章的 S-02](https://quickstart.to/go-global/payments) 时间线；可选下载本地演练，或只读静态材料。假设 11 月续费失败，11 月 4 日先更新卡资料，再确认这一期补付；随后旧期退款和重复通知到达。

解释每一步是否能生成报告、恢复到什么时候，以及为什么。另说说如果退回的是 11 月这笔钱，会怎样改变判断。最后说明你还需要做哪些事，才能把本地演练用于自己的真实服务。不要连接真实支付账户或填写密钥。

## T5：为自己的条件整理一份可核对的问题

使用 [合规](https://quickstart.to/go-global/compliance)、[身份与主体](https://quickstart.to/go-global/entity) 和 [税务](https://quickstart.to/go-global/tax)，按你目前的经营地、交付方式和数据路径，找出下一次行动前必须确认的一项条件。还没有业务时，可以明确使用书中的教学情境。

交回一份脱敏问题说明：已知业务事实、缺少的材料、准备向谁询问、什么答复会改变下一步，以及等待期间能做什么。不需要取得真实法律/税务意见，也不要填写地址、证件、账户或客户信息。

## T6：把真实卡点留在原文旁，再找回处理结果

只在你本轮确实遇到不明白、有误、过期或需要补充资料的地方做这项任务。使用相关页面的反馈入口，按自己的意愿提交，然后找到本人反馈。没有实际问题时，告诉组织者“这次没有触发”，不要为了任务编造一条问题。

组织者处理后，再回到“我的反馈”查看：你能否找到原问题、理解处理依据，并判断是否需要进一步说明？本轮邮件通知未开放，后续查看时间由你和组织者约定。提交成功与收到可理解的处理结果是两个阶段；尚未收到结果时可以先结束本次试读，不需要等待在页面上。

这项任务无需删除账号。你若自行选择导出或删除，请先看隐私说明；组织者不会替你执行这些操作。
