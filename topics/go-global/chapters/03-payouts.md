先确认平台能把这类业务款打到你的本人账户，再接入支付。每次回款分别记录客户付款、平台出款和账户入账，以实际入账凭证完成验收。

本章承接[快速入门](/go-global)，讨论中国大陆个人通过代收款平台（Merchant of Record，MoR）销售软件后的回款。平台候选与产品准入见[收款方案全景](/go-global/payments)。这里的币种、费用与规则依据截至 **2026-10-08** 核验的官方文档；尚未用中国个人账户完成真实出款测试，具体银行、支付宝账户与所得分类仍需个案确认。

## 先画出自己的资金路径

在准备收款账户时，写出一行完整记录：

> 客户支付币种 → 平台结算余额币种 → 平台出款通道及币种 → 本人接收账户 → 实际入账币种。

不要把每个箭头都默认成美元。Paddle 支持的出款币种包含 CNY；Creem 的中国个人路径明确为支付宝；Dodo 则要求绑定银行前确认所在国家可用的通道、币种和入账方式。[^src-paddle-payout-currency][^src-creem-payouts][^src-dodo-payouts]

按自己准备使用的账户核对下面这张表：

| 平台 | 官方文档列出的路径 | 绑定前要取得的答复 |
|---|---|---|
| Paddle | 电汇或 Payoneer；可选出款币种含 CNY。[^src-paddle-payout-schedule][^src-paddle-payout-currency] | 你的银行或 Payoneer 账户是否接受该类业务款；最终接收币种、费用及所需材料 |
| Creem | 中国个人收款人为支付宝账户，企业为本地银行账户；个人受益人姓名须匹配身份验证（KYC）资料。[^src-creem-payouts] | 本人账户是否适用、实际额度档位、支付宝通道的具体费用及换汇方式 |
| Dodo | 个人使用本人同名银行账户，通道及币种因国家而异。[^src-dodo-verification][^src-dodo-payouts] | 银行能否接收平台使用的转账方式，能否保留所选外币，银行与中转行如何收费 |

这里没有验证“某一家大陆银行一定可收”，也没有验证 Payoneer 对每个个人软件经营场景的适用性。把平台支持、收款机构接受、个人账户适用分别问清，再把答复保存到自己的回款档案。

## 余额在哪个阶段，决定下一步做什么

可以用下列五个阶段整理自己的记录；它们是核对顺序，不要求平台后台使用完全相同的名称。

| 阶段 | 你要看的证据 | 下一步 |
|---|---|---|
| 客户已付款 | 真实订单、交付记录 | 核对退款、交易税和平台扣费 |
| 余额等待释放 | 后台的待结算、冻结或风险审核记录 | 查看解除条件，不按累计销售额申请出款 |
| 余额可出款 | 合格余额、门槛和出款启用状态 | 检查是否需要手动申请及下个窗口 |
| 平台已发出 | 出款编号、金额、币种、发送日期和收款账户 | 向接收账户核对入账 |
| 本人账户已入账 | 银行或支付宝实际入账凭证 | 对账，并按已确认的方式处理相关申报 |

这些区别会实际影响等待时间：Creem 的款项可能先保留7–12日用于风险评估；Dodo 在开户验证之外还有出款所需的 `Monitoring Review`，其出款状态 `Success` 只表示已经发往银行。[^src-creem-payouts][^src-dodo-verification][^src-dodo-payouts]

例如，后台已有一笔真实订单，但款项还未释放，就先处理“余额可用”条件；即使余额可用，未达门槛或错过本期窗口，也不能将其记作已到账。不要用自己的测试订单补齐真实销售记录。

## 把门槛、申请动作与出款日放在一起看

以下为2026-10-08核验的文档口径。表中日期是平台处理日程，到账仍需核对接收账户。[^src-paddle-payout-schedule][^src-creem-payouts][^src-dodo-payouts]

| 平台 | 金额条件与操作 | 处理日程 |
|---|---|---|
| Paddle | 最低门槛为100美元；GBP/EUR余额对应100英镑/欧元。按账户设置及余额判断，未满足条件则结转；不支持随时提现。 | 每月1日按门槛转成出款，15日前发出；官方估计发出后到账最多还可能需要3个工作日。[^src-paddle-payout-schedule] |
| Creem | 最低可用余额50 USD/EUR，点击 `withdraw` 加入出款队列；先考虑7–12日的风险评估等待。 | 下一可用窗口为每月1日或15日；遇节假日可能顺延。[^src-creem-payouts] |
| Dodo | 默认门槛100美元，可设的最低门槛50美元；余额符合条件且相关验证完成。 | 默认半月周期：上半月在当月18日、下半月在次月4日发起；遇周末及美国联储银行假日顺延。[^src-dodo-verification][^src-dodo-payouts] |

自己的日历至少留四项：**余额达到条件的日期、申请日期、预计发出窗口、实际入账日期。** 如果只写“客户某日付款”，后续就无法判断时间花在了风险评估、平台排期还是银行处理。

## 交易费之外，还要算出款与换汇

交易环节的价格比较见[收款方案全景](/go-global/payments)。本节只补上回款环节。

| 平台 | 官方披露的出款或换汇费用 | 使用时的边界 |
|---|---|---|
| Paddle | 出款币种与银行所在国不匹配而走 SWIFT 时，列有15 USD/EUR/GBP电汇费；出款币种不同于余额币种时，汇兑差最多1.5%。[^src-paddle-payout-fees][^src-paddle-payout-currency] | 要先确认你实际走哪条通道，不能把15美元套到所有CNY出款 |
| Creem | 通用出款费按7 USD/EUR与金额的1%取高；支付合作方换汇可能另收费。[^src-creem-payouts] | 文档未在中国支付宝说明处单列完整报价，绑定前询问实际适用费用 |
| Dodo | 标准定价列明低于1000美元的出款收5美元，非美国商户USD SWIFT出款另列25美元；银行与中转行可能再收费。[^src-dodo-pricing][^src-dodo-payouts] | 小额出款费与SWIFT费是否同时落到你的路径，按实际通道确认 |

固定费用对小额回款的影响可以直接算。**仅假设某笔出款适用 Creem 文档中的通用费率**：50美元出款的该项费用为7美元，占14%；500美元仍为7美元，占1.4%；1000美元则为10美元，占1%。这是按公开公式演算，未包含交易费、换汇、其他机构收费，也不是中国支付宝通道的报价。[^src-creem-payouts]

决定出款频率时，把资金使用时间和费用一起比较。不要为了降低费用而把“平台余额”和“自己已经收到的钱”合并记账。

## 用一张表解释到账差额

先保存真实订单，再按平台结算期间汇总。Dodo 的结算单会列付款、交易税、费用及此前余额等项目，因此一笔出款不一定只对应本期的一笔订单。[^src-dodo-payouts]

下面是**虚构的对账演算**，所有金额都假设以美元计价，并假设列出的各项已反映在同一结算期间。它不代表任何平台的费率、税率或会计处理规则。

| 项目 | 示例金额 |
|---|---:|
| 期初可结算余额 | 40.00 |
| 本期客户支付总额 | +500.00 |
| 其中应扣交易税 | −30.00 |
| 交易费用 | −25.00 |
| 退款扣减 | −45.00 |
| 本期尚未释放、留到后期的金额 | −100.00 |
| 本期拟出款额 | **340.00** |
| 出款费用 | −7.00 |
| 平台实际发出金额 | **333.00** |
| 接收环节额外费用 | −3.00 |
| 本人账户实际入账 | **330.00** |

核对顺序是 `40 + 500 − 30 − 25 − 45 − 100 = 340`，再对齐出款和入账费用。真实账单如果把费用合并展示、提前扣除或另行收取，按账单重建计算，避免重复扣费。

发生换汇时，增加“换汇前金额与币种、适用汇率、换汇后金额、额外费用”几列。只在同一币种下加减；找不到差额原因时，保留未解释项，不自行改成“汇率损失”让账面凑平。

建议每期保存以下材料，并用出款编号把它们关联起来。这是一套对账准备清单，不代表所有银行统一要求这些文件：

- 订单明细、真实交付和退款记录。
- 平台协议、产品说明与当期结算单。
- 出款编号、平台发送日期、收款账户和费用明细。
- 接收机构入账凭证、换汇记录及相关咨询答复。

## 收汇、结汇与申报，分别确认

平台费用表解决的是“转多少钱、扣多少费”；外汇与税务规则需要另行核对，不能从“款项已到账”倒推所有手续已完成。

### 年度5万美元不是境外收入上限

《个人外汇管理办法实施细则》第二条将个人结汇和境内个人购汇的年度总额分别设为每人每年等值5万美元，并规定超过年度总额的办理路径。因此不能把它写成“每年只能从境外收到5万美元”，也不能据此保证任何收入都能按同一方式结汇。[^src-safe-individual-fx-rules]

同一细则第八条区分经营性与非经营性外汇收支；第十条列举境内个人非经营性结汇超过年度总额时的证明材料，其中专有权利使用和特许收入包括付款证明、协议或合同。这是对应类别的条文，不代表所有软件或SaaS收入自动属于该类别。[^src-safe-individual-fx-rules]

带着自己的合同、交付方式和结算单向开户行询问：

> 我以［实际身份或经营形式］提供［软件许可、持续服务或其他真实交付］，由［合同付款方］通过［通道］汇入本人［账户类型］。请确认该收入适用的业务类别、账户与结汇路径，需要哪些真实性材料；超过相关年度总额时应怎样办理？

Creem 文档还列有中国个人支付宝单笔5万元、年度30万至60万元的通道限制；年度档位需确认。该平台限额与外汇细则的年度总额来自不同规则，不能相互替代，也不能按最高档预估自己的额度。[^src-creem-payouts][^src-safe-individual-fx-rules]

### 国际收支申报中的“免填”，有明确范围

截至2026-10-08，本章依据汇发〔2022〕22号附件说明通过银行进行国际收支申报的规则：涉及外汇，也涉及符合该细则范围的人民币涉外收付款。居民个人单笔等值1万美元以下（含1万美元），可免填涉外收付凭证中的**申报信息**；银行仍须报送基础信息，申报主体仍须配合。[^src-safe-bop-rules-2022]

需要申报的涉外收入，附件第十二条规定在解付银行解付日或结汇中转行结汇日后五个工作日内办理。具体通道是否适用该规则、由哪家机构通知和办理，应在收款前问清，不能把银行路径直接套给所有支付机构路径。[^src-safe-bop-rules-2022]

这里的免填不等于免交易审核，更不等于免税。不要为了套用限额拆分交易。外汇局已于2026年9月30日发布修订征求意见通知，反馈截止2026年10月30日；截至本轮核验，引用的该通知是征求意见文件，本章未将草案条款当成已生效要求。后续操作时应复查最终文件及其生效日。[^src-safe-bop-rules-2022][^src-safe-bop-consultation-2026]

### 境外付款不自动决定个税所得来源

《个人所得税法实施条例》第三条按劳务提供地、权利使用地等判断境内所得，不以付款地点为唯一依据；第六条另行定义劳务报酬、特许权使用费和经营所得。不能仅凭“平台在境外”或“产品叫软件”，直接确定所得来源和类别。[^src-tax-iit-implementation]

只有实际适用居民个人境外所得规定时，才引用2020年第3号公告的次年3月1日至6月30日申报期间。先把居民身份、所得类别、所得来源和申报安排分别确认，再确定自己的办理时间。[^src-tax-foreign-income-2020-3]

本轮公开检索未找到对“中国大陆个人在境内开发、通过境外MoR持续销售软件”统一定性的明确答复。可将前面的业务描述和实际材料交给主管税务机关，询问各项应如何判断；不要把本章的对账示例当作应税收入计算表。

## 钱没到，按停留阶段排查

| 看到的情况 | 先查什么 | 向谁提供什么 |
|---|---|---|
| 已有订单，但可用余额不足 | 扣费、退款、风险评估等待、门槛 | 向平台提供订单与余额差异，询问释放条件 |
| 余额够，但没有出款单 | 出款是否启用，Creem是否已申请，是否进入本期窗口 | 向平台提供账户审核状态、申请日期及所查窗口；对应条件见上表。[^src-creem-payouts][^src-dodo-verification][^src-paddle-payout-schedule] |
| 已显示发出，但本人账户未入账 | 发往哪个账户，金额、币种及发送日期 | 先请接收机构查款；找不到时，带出款编号回到平台追踪。Dodo文档给出的也是这一顺序。[^src-dodo-payouts] |
| 收到补充材料或退汇通知 | 通知中的实际原因，收款信息与业务描述是否一致 | 按要求补交易证明或更正账户信息；保存处理记录 |
| 到账金额少于预期 | 平台出款费、换汇、银行及中转行扣费 | 将结算单与入账凭证逐项对齐；Dodo明确说明接收环节收费可能减少实收。[^src-dodo-payouts] |

排查记录只保留与交易有关的必要资料。向机构发送材料时使用其官方支持渠道；账户信息和身份证明保存在自己的私密档案中，不放到公开反馈区。

## 接下来怎么用

回到[快速入门](/go-global)，把所选平台的出款条件填入自己的执行清单。若还未选平台，先读[收款方案全景](/go-global/payments)。每次回款完成后，把订单、平台结算和实际入账三部分对上，再进入下一期。

规则变更会记录在[专题变更记录](/go-global/changelog)。本章的来源列表可用于定位平台原文及外汇局、税务总局文件。
