# 大纲：中国开发者出海（草案）

> 状态：草案，待调研档案（`research/`）验证主线后通过 PR 定稿。

## 读者

中国大陆个人开发者：一个人、没有海外公司、会写代码，想把软件卖给海外用户。

## 快速入门主线（待验证假设）

个人身份 + Merchant of Record（MoR）平台收款 + Web 产品（SaaS / 工具 / 数字商品）→ 提现到个人账户 → 收到第一笔美元。

需要在调研中回答的问题：

1. 哪些 MoR 平台接受中国大陆个人卖家？准入条件、KYC 要求、禁售类目？
2. 提现路径：平台支持哪些出款方式？到中国大陆个人账户的可行链路与成本？
3. 外汇与个人所得：个人收汇的额度与申报要求？
4. 主线整体耗时与最低成本估算。

若主线不成立，在调研档案中给出替代主线并提交讨论。
