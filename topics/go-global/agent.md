# 本主题的写作说明（给 Agent）

继承仓库根目录 `AGENTS.md` 与 `docs/content-guide.md`，以下为本主题补充。

## 读者与口吻

- 读者：中国大陆个人开发者，技术能力强，但对支付、外汇、税务、海外合规不熟。
- 口吻：有经验的同行在分享，直接、具体、给结论。不说教，不堆砌“注意事项”。
- 技术细节点到为止（读者会写代码）；把篇幅留给支付、合规、钱怎么回国这类读者最缺的知识。

## 硬性要求

- 涉及费率、准入条件、政策、额度的每一句都必须有引用，且来源优先级：平台官方文档 / 政府与监管机构官网 > 平台官方博客 > 有署名的一手经验帖。二手汇总文章只能作为调研线索。
- 不确定某平台是否接受中国大陆个人时，必须写明“截至某日期，官方文档的表述是……”，不能凭印象下结论。
- 外汇与税务内容统一引用国家外汇管理局、国家税务总局等官方来源，并附免责声明（已在 `topic.yaml` 中配置）。
- 不推荐任何违规绕过方式（例如借用他人身份开户、虚构经营信息）。读者问到时，说明风险并给出合规路径。
