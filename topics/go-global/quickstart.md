## 这份快速入门会带你完成什么

读完并照做后，你应该能够：

1. 选定一个适合个人开发者的收款平台并完成开户；
2. 把支付接入你的 Web 产品；
3. 定好价格并上线；
4. 收到第一笔来自海外用户的付款，并把钱提现到自己的账户。

## 适合谁

- 你在中国大陆，一个人开发；
- 你还没有海外公司；
- 你做的是 Web 产品：SaaS、在线工具或数字商品。

做 App、或已经有海外公司的读者，后续章节会有专门的分支路线。
