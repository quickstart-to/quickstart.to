# Revenue per thousand impressions (RPM)

来源：https://support.google.com/adsense/answer/190515?hl=en

读取：2026-10-10，Ego TaskSpace 82。

> RPM = (Estimated earnings / Number of page views) * 1000

定位：定义、计算公式与两个例子；官方页面分别展示 Page views 和 ad impressions。正文 3 美元是自设演示值，不是平台典型报价。

采用范围：RPM 为估计收益除以对应页面浏览、广告展示或查询数再乘 1000；页面 RPM 与广告展示 RPM 分母不同，不是实际已到账收益。
