# Managing Subscriptions

- 来源：https://docs.creem.io/features/subscriptions/managing
- 发布方：Creem
- 核验日期：2026-10-09
- 结论：升级/降级立即生效，差额处理按update_behavior；改产品价格仅用于新结账，既有订阅不自动变价且迁移不自动通知客户
- 置信度：confirmed（官方公开文档；不是个案审核或实测）

> Existing subscriptions keep billing at the price they signed up with.

2026-10-09 定价精修再次读取：Update Behavior Options 开头说明方案变更立即生效；表格分别列出立即按比例收退差额及不收退差额。Changing a Product’s Price 限定新结账；Raising Prices for Existing Subscribers 要求新建同币种/周期产品后逐笔迁移，并明确平台不发送变价通知。正文未执行任何真实迁移，也未照搬批量命令。
