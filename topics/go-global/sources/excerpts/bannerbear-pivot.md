# Bannerbear：从技术用途回到重复工作

- 原文：https://www.bannerbear.com/blog/the-pivot/
- 作者Jon Yongfook；页面标注2020年1月；核验2026-10-09。
- 类型attributed experience，reported；厂商创始人的转向公告，有推广利益，尚不包含后续成功的独立证据。
- 定位：What is Open Graph?、I Make Banners、Spreading Myself too Thin。

> I don't need open graph but can it make XYZ size instead?

作者描述Previewmojo于2019年11月发布，发布热度退去后发现部分用户不认识或不优先需要Open Graph，任务频率不高；反复听到其他图片尺寸的请求，因此转向更广的图片用途。也放弃多个产品并行，收拢投入。本文不采纳其普遍50/50时间分配主张，不以这篇公告证明转向已成功。

2026-10-10 重新阅读：用于 AI/API 专项的任务频率与入口取舍，仍仅采用 2020 年原作者转向叙述，不把后续产品成绩归因于这一决定。
