# No License

来源：https://choosealicense.com/no-permission/
阅读日期：2026-10-10

> Neither site terms nor jurisdiction-specific copyright limitations are sufficient for the kinds of collaboration

定位与核验范围：第二段及使用无许可代码的建议；confirmed 为该指南的说明，非个案裁判。

采用结论：公开 GitHub 仓库的查看/fork 条件不等于一般开源再利用许可；没有许可时应询问、协商或选择替代，保留法律例外的适用边界。
