# Supported Regions Policy

阅读：2026-10-10。来源：https://www.anthropic.com/supported-countries

> Any country or region not listed is unsupported.

页面开头适用范围、三个 unsupported 条目及完整地区列表；confirmed。精确范围包括不受支持地区实体的人员，即使人位于支持地区。
