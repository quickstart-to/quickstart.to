# About keyword matching options

- URL: https://support.google.com/google-ads/answer/7478529?hl=en
- Accessed: 2026-10-10
- 定位：Keyword match types → 展开的 Phrase match / Exact match

> Ads may show on searches that have the same meaning or same intent as the keyword.

支持范围：正向 phrase/exact 按含义或意图匹配，不是逐字比较；宽匹配覆盖更广，平台推荐与 Smart Bidding 搭配，本文窄范围探索是有代价的教学取舍。
