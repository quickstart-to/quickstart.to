# Test Mode

- Source: https://docs.creem.io/getting-started/test-mode
- Publisher: Creem

> All API calls, payments, webhooks, and data are kept separate from your production environment, ensuring you can develop with confidence.

> Test and production environments use different API keys.

> Register your production webhook URL in the live dashboard

> Switch to production mode in the dashboard and create your live products
