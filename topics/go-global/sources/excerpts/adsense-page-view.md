# Page view

来源：https://support.google.com/adsense/answer/191124?hl=en

读取：2026-10-10，Ego TaskSpace 82。

> A page view is what Google counts in your reports every time a user views a page displaying Google ads.

定位：正文定义与 3 个广告位、查看 2 次仍为 2 次 Page views 的例子。用于限制演算分母，不把普通站点全量 PV 当作广告报表量。

采用范围：AdSense 页面浏览量按访问展示 Google 广告的页面计算，同页广告位数量不改变一次页面浏览的计数。
