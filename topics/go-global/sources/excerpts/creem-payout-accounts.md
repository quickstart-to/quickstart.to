# Payout Accounts

- Source: https://docs.creem.io/merchant-of-record/finance/payout-accounts
- Publisher: Creem
- Accessed: 2026-10-09

> The full onboarding flow is: Business Details → KYC/KYB Verification → Payout Account Setup → Account Review by Creem Team → Live Payments Enabled.

> Payouts will always be sent to the default account.

## 2026-10-09 样章复核定位

定位：Setting Up a Payout Account列Business Details → KYC/KYB → Payout Account → Account Review → Live Payments；Available Payout Methods区分Bank Transfer费用和Alipay；Setting a Default Payout Account说明向默认账户发送。具体个人资料尚未申请，本书没有模拟真实审核。

## 2026-10-09 提现章复核

定位：Available Payout Methods 表将 $7 or 1% 放在 Bank Transfer 行，Alipay 行只列中国商户及单笔上限。Setting a Default Payout Account / Multiple Stores：每店独立设置，出款发往默认账户。不能将银行报价写成支付宝报价。
