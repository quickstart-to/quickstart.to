# Comprehensive clearance search for similar trademarks

来源：https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks
阅读日期：2026-10-10

> You should search for trademarks that are confusingly similar to yours

> We also recommend you search for common-law use

定位与核验范围：指南正文及 comprehensive clearance 的清单；confirmed，仅限指南描述。

采用结论：美国商标清查指南涵盖相同或相关商品服务的近似标志、联邦登记与互联网普通法使用等；不将无检索结果等同允许使用或注册。
