# About primary and secondary conversion actions

- URL: https://support.google.com/google-ads/answer/11461796?hl=en
- Accessed: 2026-10-10
- 定位：The difference between primary and secondary actions；custom goal exception

> Secondary actions: These conversion actions are for observation only.

支持范围：主要转化在其标准目标用于出价时参与优化并进入 Conversions；次要通常仅观察，但加入 custom goal 也会参与出价，不承诺改成次要即可在任何情况下排除。
