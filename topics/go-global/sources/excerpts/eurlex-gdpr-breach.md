# GDPR consolidated text — Articles 3, 33 and 34

- 来源：https://eur-lex.europa.eu/legal-content/EN/AUTO/?uri=CELEX:02016R0679-20160504
- 入口：https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng 的 current consolidated version 链接
- 发布方：EUR-Lex；实读：2026-10-09；置信度：confirmed，仅下列条文

> The processor shall notify the controller without undue delay after becoming aware of a personal data breach.

精确定位：第三条包括欧盟设立情形，以及非欧盟机构向在欧盟的人提供商品/服务或监测其在欧盟行为等条件，不能仅以英语站点判定适用。第三十三条第一款：控制者无不当延迟、可行时在知悉后 72 小时内通知主管监管机关；不太可能对个人权利和自由造成风险时例外，迟报说明理由。第二款为处理者及时告知控制者。第三/四款列通知内容并允许分阶段及时补充。第五款由控制者记录所有个人数据泄露的事实、影响与补救。

第三十四条第一款：很可能造成高风险时，无不当延迟告知个人。第三款的保护措施、后续消除高风险、不相称努力及等效公开沟通分别有条件；这些不是所有加密数据或所有低风险事件的统一免报规则。监管通知与个人通知不能合并为“所有人 72 小时内发邮件”。
