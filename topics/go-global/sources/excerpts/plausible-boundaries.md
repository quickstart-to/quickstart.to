# Plausible：主动放弃的能力
- 来源：https://plausible.io/when-not-to-use-plausible
- 发布者：Plausible Analytics；页面未显示明确发布日期；核验：2026-10-09。
- 类型：vendor practice / product self-description；状态：confirmed仅限厂商公开描述。
- 定位：Plausible is not a session replay or heatmap tool；Plausible is not for tracking individual users；Plausible should not be used to collect sensitive personal data。
> Plausible does not record individual visitor sessions.
> that guarantee depends on how you configure it.
- 支持范围：其选择不提供回放/跨会话个人历史，并提醒URL、查询参数、自定义事件和属性不要携带个人资料。
- 限制：商业厂商，有推广利益；未实测产品，不将其“无需同意即合规”等概括迁移到本书。Cookie与合法依据另依官方资料。


## 2026-10-09 合规终审复核

全文重读：Session replay、individual users、sensitive personal data 小节支持无会话回放/个人跨会话历史，以及配置不能携带敏感内容。只采用能力边界和信息最少化的取舍，排除页面厂商的全面合规/免横幅承诺。
