# What's the difference between earnings and payments?

来源：https://support.google.com/adsense/answer/9745?hl=en

读取：2026-10-10，Ego TaskSpace 82。

> Finalized earnings - total earnings with all invalid activity deducted.

定位：Estimated earnings、Finalized earnings、Earnings、Balance 定义；未采用时区细节。300 → 270 → 0 仅教学记录，非平台固定扣减比率。

采用范围：区分当月估计收益、扣除无效活动后的最终收益和含借贷调整的余额；不提供所有账户统一付款时间或到账承诺。
