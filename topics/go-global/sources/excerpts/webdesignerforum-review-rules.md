# Website Review Rules

- 来源：https://www.webdesignerforum.co.uk/topic/1997-website-review-rules/
- 作者：公开管理员 Jo 90；页面发布日期：2007-10-13；核验：2026-10-09。
- 当日从 Website Reviews and Feedback 版的置顶主题进入并阅读全文。页面古老，不把核验日当作规则新发布日期。
> You need a total of 5+ posts to create a topic/reply
- 采用：规则要求只为广告/链接而发帖的成员使用 Classified Advertising Section，强调尊重花时间评审的人；列出发帖/回复门槛。
- 边界：没有实际登录测试权限，不能保证今日产品权限一定与文字一致；不建议为门槛灌水、不把网站评审许可解释成用户招募许可。
