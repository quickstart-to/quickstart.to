# 中华人民共和国个人所得税法实施条例

- Source: https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194444/content.html
- Publisher: 国家税务总局政策法规库
- Accessed: 2026-10-08
- Version: 国务院令第707号，2018-12-18第四次修订；页面标示“全文有效”

第三条及第（一）项：

> 除国务院财政、税务主管部门另有规定外，下列所得，不论支付地点是否在中国境内，均为来源于中国境内的所得：
> （一）因任职、受雇、履约等在中国境内提供劳务取得的所得；

第六条第（四）项：

> 特许权使用费所得，是指个人提供专利权、商标权、著作权、非专利技术以及其他特许权的使用权取得的所得；提供著作权的使用权取得的所得，不包括稿酬所得。

第六条末段：

> 个人取得的所得，难以界定应纳税所得项目的，由国务院税务主管部门确定。

另核对第六条第（二）项含技术服务等劳务，第（五）项含个人从事其他生产、经营活动取得的所得。以上是分类规则，不能单凭这一条文把所有 MoR 软件销售收入统一定性。

2026-10-08补核：第二条将住所与户籍、家庭、经济利益导致的习惯性居住联系；第三十二条分别规定外币所得一般申报及年度汇算补税的折算规则。税务折算不得直接用银行实际换汇价替代；第二十二条要求境外纳税凭证。
