# How to set up an ad campaign in TikTok Ads Manager

- URL: https://ads.tiktok.com/help/article/campaign-set-up?lang=en
- Accessed: 2026-10-10
- 定位：Last updated October 2025；How to set up an ad campaign

> Manual campaigns allow you to use the standard workflow to maximize control for your ads settings.

支持范围：campaign/ad group/ad 三层；创建时选择目标和 Manual/Search/Smart+，关联 TikTok 账号或 Authorized post、预算等，保存草稿及发布前复核；不混同三类系列。
