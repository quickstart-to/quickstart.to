# 中华人民共和国增值税法实施条例

- Source: https://fgk.chinatax.gov.cn/zcfgk/c100010/c5246349/content.html
- Publisher: 国家税务总局政策法规库
- Accessed: 2026-10-09

> 自然人属于小规模纳税人。

核对第2、3、7、9、17、39、48、54条。服务与无形资产需按真实合同分类；不把个人、外币收款或客户在海外当作自动零税率/免税，也不把同一收款数字套作个税、增值税两种口径。
